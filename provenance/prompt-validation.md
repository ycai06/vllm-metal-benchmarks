# Prompt generator validation

The initial generator estimated repetition count from an isolated sentence. At 4,096 requested input tokens, boundary token merging left only 3,995–3,996 tokens. The client raised before any warmup or measured HTTP request for that condition. Completed 256/1,024-token trials were preserved.

The corrected generator extends repeated text until tokenization is at least the requested length, then truncates the token-ID list. Independent read-only verification checked 24 prompts at each length 256/1,024/4,096 for seeds 713 and 17, deterministic reproduction, exact lengths, and byte-for-byte equivalence with the original generator at 256/1,024 tokens. All 227 pre-existing raw request prompt hashes (including the excluded smoke test and warmups) matched regenerated inputs. Full-suite resume was also reviewed: successful trials are skipped and new server directories preserve previous files.
